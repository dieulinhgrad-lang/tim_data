# Lịch sử tìm agent hằng ngày

Mỗi ngày (giờ Việt Nam):
- `<ngày>.csv`: các agent mới trong ngày, cùng cột với Google Sheet
- `<ngày>-report.md`: báo cáo ngày
- `<ngày>-candidates.csv`, `<ngày>-lanes.json`, `<ngày>-quals.json`, `<ngày>-sheet-rows.json`: dữ liệu trung gian
  (chỉ có ở chế độ Claude Code tự nghiên cứu)

Thư mục này cùng với Google Sheet là "bộ nhớ" để không tìm trùng agent giữa các ngày.
